## WeChat Local Archive v0.2.4

中文 Web 界面与首次使用体验更新。核心归档格式、数据库读取方式和命令行参数保持不变。Windows 普通用户现在直接下载一个独立 EXE，不需要预装 Python、uv 或开发工具，也不需要管理员权限。

### 使用

下载 `WeChatLocalArchive.exe` 后直接双击。程序只在 `127.0.0.1` 启动本地 HTTP 服务并自动打开默认浏览器，不需要解压应用目录，也不依赖旁边的 `_internal` 文件夹。支持 Windows 10/11 x64。

首次使用需要已登录的 Windows 微信 4.x 完成本地初始化。之后可使用缓存密钥离线归档。默认输出到“下载\wechat-local-archive”，设置与 DPAPI 加密密钥保存在 `%LOCALAPPDATA%\WeChatLocalArchive`；删除 EXE 不会删除这些数据。

### 本版内容

- 本地 Web 主流程：首次初始化、搜索/选择聊天、开始归档、进度与安全取消、查看和检查结果。
- PyInstaller onefile 单 EXE 分发；Web 静态资源、离线阅读器和运行时依赖随 EXE 打包。
- 增量、幂等归档与完整性验证；保留已有附件和转写缓存。
- 日期范围、媒体选择和语音转写资源档位收进“更多选项”，默认仍保存媒体并转写语音。
- `archive.json` 真源、`chat.md`、精简 `ai.jsonl` 和离线 `chat.html` 阅读器。
- SenseVoice 本地批量转写与资源档位；浏览器语音播放使用本地 MP3 缓存。
- 可选 Whisper 复核代码及来源记录；基础 EXE 不包含 Whisper 模型权重。

### 隐私清理说明

旧版本的公开发布附件已撤下，当前发布文件从清理后的源码重新构建。旧 Git 提交已不在当前分支和标签中，但旧 SHA 及第三方缓存仍可能保留历史内容。本地已有归档和 DPAPI 密钥不需要迁移或重置。

### 隐私与限制

发布文件不包含聊天记录、数据库密钥、模型权重或个人缓存。首次 SenseVoice 模型下载需要网络，之后可离线使用。工具不会发送或修改微信消息，不是微信官方产品。数据库密钥提取仍依赖第三方本地实现，不保证兼容所有微信版本。

本版未进行独立代码签名。若 Windows 显示安全提示，请核对 GitHub 发布来源和 SHA256，不要关闭系统安全保护。PyInstaller onefile 首次启动时会把运行时解包到系统临时目录，这是正常行为；归档和配置不会保存在该临时目录。

### 校验

同页提供 `WeChatLocalArchive.exe.sha256`。发布 CI 会校验 tag 与源码版本、EXE 的 SHA256，并在只放置单个主 EXE 的隔离目录中启动本地 Web smoke，确认无需 `_internal` 或源码目录。
